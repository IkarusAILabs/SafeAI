# Authority Evidence Validation — validation report (v2.6, hardened)

Status: measured evidence. Machine record: `evaluation.json`; reviewer
brief: `brief.md`. Both generated by `safeai benchmark` (default path:
repeat + order-shuffle determinism checks on every case).

Reproduce: `python -m safeai.cmd.cli benchmark --json evaluation.json
--markdown brief.md` from the repo root (offline, no network, no
execution of scanned code). Exit 0 means every case holds; exit 1
names the mismatched cases; exit 2 is a harness error (never a
measurement).

This is a research artifact about SafeAI ("how well SafeAI performs
on a fixed corpus"). It never belongs inside a customer scan report
("your project"): customer reports contain no benchmark numbers
(enforced by `test_customer_reports_contain_no_benchmark_numbers`).

## Methodology (what the numbers prove)

- 56 cases pair minimal agent/IaC inputs with hand-verified,
  implementation-independent canonical gold truth
  (`truth_schema_version: "2.0"`, `annotation: {basis:
  human_reviewed_source, confidence}`): human agents, tools,
  capabilities, identities, grants, relationships, authority
  statements, expected material changes, unknown expectations. Gold
  never encodes scanner internals (`unknown:unattributed` appears in
  no gold file — verified by test).
- The harness projects scan output into the same canonical shape and
  compares by neutral keys (names, kinds, namespaces, slugs), never by
  `tool_key` strings.
- Entity discovery, 8 attribution levels, material-change/escalation
  PRF, unknown preservation, evidence completeness, and determinism
  are measured independently. A missing gold section reports
  `insufficient_evidence`, never 0/1; rates with empty denominators
  do the same (a system predicting nothing has proven nothing).
- Baseline pairs assert an expected materiality per entry
  (`NO_CHANGE … AUTHORITY_ESCALATION … UNKNOWN_CHANGE`) plus whether
  the surface should show it (`surface_expected`). Entries outside
  the surface model are counted blind spots (3), with detection still
  enforced via findings/summary channels — explicit per-entry gold,
  not a hidden hatch.
- Lane-A verdicts are per-class (capability detection, identity
  attribution, authority attribution, change detection, escalation
  detection) against PROPOSED bars (ADR-0008; no gate consumes them).
  Authority attribution gates on the end-to-end rate over ALL
  exercised capabilities including the unattributed bucket. Any
  observed unknown/unresolved evidence vetoes overall readiness.

## Results (measured on corpus, not universal guarantees)

56/56 cases hold; determinism 56/56; aggregate digest in
`evaluation.json` byte-compares across runs.

Discovery (harness-calibration rows; they move only when scanner or
truth changes): agents 31/31, tools 17/17, capabilities 121/121,
identities 22/22, grants 17/17, relationships 79/79, statements 16/16
(all P/R/F1 1.0). Rule-level detection (rule firing only, not
authority discovery): P/R/F1 1.0 (59 TP, 0 FP, 0 FN).

Attribution levels (all 1.0 where gold permits): tool 17, capability
58, agent 31, identity 24, grant 18, agent→identity 5,
capability→grant 16, complete-chain end-to-end 5/5. End-to-end legacy
rate including the unattributed bucket: **0.464 (58/125)**;
attributable-only accuracy 1.0 (58/58). 67 capabilities sit in
`unknown:unattributed` (code-defined tools) — up from 52/90 because
19 targeted attribution/unknown cases were added, not because the
scanner improved. The rate rose 0.4222 → 0.464 purely from corpus mix
(more attributable MCP cases); the gap itself is unchanged and stays
visible. No benchmark change was made to raise any score.

ChangeGuard (9 baseline pairs, 7 tool-surface entries + identity/grant
domains): material-change P/R/F1 1.0 (5 TP), escalation P/R/F1 1.0
(4 TP), observed false-escalation rate on benchmark corpus 0.0
(4 HIGH_RISK observed, genuinely measured — not 0/0),
missed-material rate 0.0, surface-blind entries 3 (explicit).

Evidence: completeness 1.0 (73/73 refs), unknown preservation recall
1.0 (43/43: UNKNOWN, UNVERIFIED_LINK, PARTIAL, INFERRED, UNRESOLVED
all stay expressed; PARTIAL matches only partially-resolved
evidence, never a downgrade), determinism 1.0.

## Lane-A verdict: RESEARCH / NOT LANE-A READY

Capability detection, identity attribution, change detection, and
escalation detection read LANE-A CANDIDATE on corpus evidence.
Authority attribution reads LANE-B (0.464 < 0.95), and 17 observed
unknown/unresolved items veto overall readiness regardless. Lane A
stays closed with quantified reasons.

## Blind spots documented (not hidden)

1. Code-defined tools land in `unknown:unattributed` (67/125 caps).
   Findings still fire; the surface cannot name the tool.
2. `agent_uses_tool` edges are beyond the current model (every such
   gold edge is `resolvable: false`, counted in relationship
   limitations, excluded from P/R denominators — never scored as
   correct).
3. Surface-blind material entries: 3 (legacy code-tool baseline
   pairs); detection via findings/summary enforced instead.
4. Repo-scoped (not tool-scoped) identity links yield UNKNOWN
   verdicts even with resolved grants (multiple_identities,
   attachment_chain pattern).
5. Change/escalation denominators are small (5/4): CANDIDATE reads
   carry visible TP counts, not large-sample confidence.
6. Sensitivity is proven, not assumed: 8-area live-logic mutation
   tests (identity, namespace, wildcard, grant, capability
   attribution, correlation, change classification, UNKNOWN
   downgrade) plus a live input-neutering test all require failure.
