# Authority Evidence Validation — validation report (v2.6)

Status: measured evidence, 2026-10-04. Machine record:
`evaluation.json`; reviewer brief: `brief.md`. Both generated by
`safeai benchmark` (default path: repeat + order-shuffle determinism
checks on every case).

Reproduce: `python -m safeai.cmd.cli benchmark --json evaluation.json
--markdown brief.md` from the repo root (offline, no network, no
execution of scanned code). Exit 0 means every case holds; exit 1
names the mismatched cases; exit 2 is a harness error (never a
measurement).

## Methodology (what the numbers prove)

- Each of the 37 cases pairs a minimal agent/IaC input with a
  hand-verified `expected/expected.json` truth (agents, tool surface +
  access modes, identities, grants, links, verdicts, change entries,
  must_fire/must_not_fire rules, evidence refs, uncertainty pools).
- The harness runs the real `safeai scan` CLI path (full postprocess:
  normalize, baseline, policy, outputs) and compares structurally.
  Outputs always land outside the scanned input.
- Baseline pairs scan `input/baseline` then `input/current` with
  `--baseline`; single-input cases scan once, then twice more for
  determinism (repeat + reversed-creation-order copy).
- Surface entries with null `tool_key` are measured as
  surface-unmeasurable, never asserted: the benchmark documents the
  attribution blind spot instead of hiding it or failing on the
  impossible. Findings/summary channels are still enforced where the
  truth claims them.
- Design deviation from `docs/architecture/
  V2_6_AUTHORITY_EVIDENCE_VALIDATION.md` §3: the authority harness is
  a separate runner (`safeai/benchmark/`, `safeai benchmark`) rather
  than an extension of `scripts/run_benchmarks.py`, so the WS4 system
  is untouched. No scan behavior changed.

## Lane-A graduation verdict: NOT eligible (correct)

PROPOSED targets (per ADR-0008, report-only, no gate consumes them):
discovery precision/recall PASS, false-escalation PASS, evidence
PASS, determinism PASS, attribution end-to-end 0.4222 < 0.95 FAIL —
plus 10 unknown/unresolved items veto class-level graduation. The
benchmark therefore reports Lane A closed with a quantified reason
(the unattributed bucket), which is the evidence the roadmap needs,
not the outcome its authors might have wished for.

## Blind spots documented (not hidden)

1. Code-defined tools land in `unknown:unattributed` (measured:
   52/90 caps). Findings still fire; the surface cannot name the tool.
2. Baseline `changes` entries without a tool_key are
   surface-unmeasurable (5 entries across baseline_changes);
   detection via findings/summary channels is enforced instead.
3. `config.yaml` role_hint (adversarial/partial_identity) is correctly
   inert: asserted via empty links + UNKNOWN verdict, with no citation
   expected.
4. Truth corrections made during harness validation (all verified
   against inputs, never blindly accepted): linked_match had no
   agent.py in input (truth now MCP-declared need only);
   namespace_confusion cited a ghost rbac.yaml (input holds only
   workload.yaml); partial_identity cited inert config.yaml.
5. Sensitivity is proven, not assumed:
   `tests/test_authority_benchmark.py::
   test_mutated_input_fails_benchmark` neuters a case input through
   the live scan path and requires failure.
